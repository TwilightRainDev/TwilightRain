# ADR-0007：提示块语法收敛为 `:::admon[...]`

## 状态

已实施

## 决策

提示块收敛为单一容器头 `:::admon[类型 可选标题]`：

- 类型移到方括号内首词（不区分大小写），其余文本 trim 后作标题——参数解析模式
  与 `:::fold[mode label]` 完全同构。
- 方括号可整体省略：`:::admon` 等价于 `:::admon[note]`（与 CSS 兜底
  `--admonitions-color-note` 的默认值一致）。
- 首词非类型时宽容兜底：`note` + 全串作标题（如 `:::admon[注意]` → note +
  标题「注意」），与 fold 的 mode 兜底先例一致；写错标题意图时不至于整块失效。
- 产物 HTML（类名、data-callout、bdm-title 结构）逐字节不变，样式零改动。
- 旧五种容器头写法（`:::note` 等）不再匹配，按普通文本原样输出（写错时显眼暴露）。

收敛理由：五种容器头各是一种拼法，读者要记五个词，且「类型 + 括号标题」与
其他扩展「方括号包首参」的惯例（`:::fold[...]`、`::card{...}`）不一致。收敛后
一个容器头一个家族，与卡片、折叠的「单指令 + 参数」心智统一；产物不变意味着零样式风险。

## 后果

全站正文与样板文统一为 `:::admon[...]`。语法唯一事实源 [GRAMMAR.md](../GRAMMAR.md)，
实现见 [THEME.md](../THEME.md)。
