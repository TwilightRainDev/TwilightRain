# 排除功能清单

拍板（2026-08-23）从 Firefly / Fuwari 候选里选出 **8 项落地、其余不做**。
本页是仓库内清单：不要按下列项开实现、也不要把缺它们当成缺陷。

当前写作语法见 [GRAMMAR.md](GRAMMAR.md)；折叠/卡片以 `:::fold`、`::card` 为准。

## 第一批：写作增强（5）

| 功能 | 排除理由 |
|------|----------|
| PlantUML | 技术文可能用到，但接入成本高，暂不引入 |
| Tab 代码块（code-group） | 过特化；现有 `:::tabs` 已能做代码对比 |
| 图表 pan-zoom | 改为自研全屏放大（当时即不在迁移范围，至今未做） |
| AI 参与度标注 | 与个人写作习惯不符 |
| 写作统计挂件 | 不需要；字数 / 阅读时间已够 |

## 第二批：站点展示（4）

| 功能 | 排除理由 |
|------|----------|
| 作品集独立页 | 与 `/projects/` 重叠；展柜 `pinned` 已够 |
| 分类导航栏（CategoryBar） | 跨分类跳转少，破坏极简 |
| 相册加密 | 前端密码门等于提示有内容，不做 |
| 热门文章页 | 文章量小，首页置顶已能突出 |

## 第三批：视需求（6，整批不做）

| 功能 | 排除理由 |
|------|----------|
| 课表页 | 非技术博客刚需 |
| IndexNow 提交 | SEO 辅助，与主题无关；若要做应走独立 CI |
| GitHub Contributions 挂件 | 纯装饰，要 token 和构建期网络 |
| 捐赠 / 赞助页 | 非刚需；真要做复制静态页即可 |
| 分享海报 | UI 工作量大，非核心 |
| 构建期 Mermaid SVG | 客户端 Mermaid 已稳定，静态化成本高 |

## 计划范围外（不计入上面 15 项）

这些从未进入拍板「要做」列表：

| 项 | 说明 |
|----|------|
| PIO / 论坛 / ACGN 页 / 密码文章 | 定位不符 |
| 大型 `ink.js` 拆分 | 单独 backlog，不为拆而拆 |
| 已删文章的 301 | 2026-08-24 决定旧 URL 允许 404（如 `bilicompact-complete`、`bilicompact-source-v2`、`blog-writing-features-part2`） |

## 不要再当成缺口的已有能力

`:::tabs`、Mermaid、`:::grid`、`:::fold`、`::card`、友链工具箱、
展柜置顶、首页布局切换、外链/邮箱保护、图片 `referrerpolicy`。
