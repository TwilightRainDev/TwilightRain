写代码的，偶尔折腾点小东西。

网名 TwilightRain，写点前端也写点桌面端。前端主要用 JavaScript / TypeScript，桌面端用 C# .NET 搞些 WinForms 小工具。平时会鼓捣一些脚本、工具、小项目。

这个博客主要用来记录技术探索和日常思考。

做过什么

  • TwilightRain Text Tool — 集行合并、文件拼接、中文截断修复、标点替换于一体的 Windows 文本处理桌面工具，纯 C# 构建，支持国际化与深色模式。
  • BiliCompact — 一个 Tampermonkey 用户脚本，用于精简 B 站网页端首页。
