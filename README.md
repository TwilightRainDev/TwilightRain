## 终端字符

本仓的源码与文档只写 ASCII 与汉字、全角标点。这套东西要分发到还停在 Windows XP 那代的机器上，那代控制台用点阵字体，字形来自当时的代码页：别的符号画出来是问号或空格，宽度也对不上，整屏跟着错位。

口径、面清单与逐字符的替代写法见工作区的 `AgentOps/ToolGate/bin/check-terminal-glyphs.mjs`。
